# form_app

Este proyecto es una aplicación Flutter creada para practicar el manejo de estado utilizando BLoC y Cubits, siguiendo el curso de Fernando Herrera.

## Características

- Ejemplos prácticos de BLoC y Cubit
- Formularios reactivos
- Arquitectura limpia y escalable

## Requisitos

- Flutter SDK
- Dart

## Ejecución

```bash
flutter pub get
flutter run
```

## Créditos

Basado en el curso de Fernando Herrera.
